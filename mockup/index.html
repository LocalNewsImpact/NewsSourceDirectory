Not connected to anything. The 159 rows are real Missouri outlets from the crawler's live source export — real names, cities, counties, owners and domains, nothing invented. Search, facets, sort, paging and export all run client-side against one loaded JSON file, exactly as the production widget would. Two notes: the export carries no frequency (empty for all 160 rows in the real data, so it is not shown rather than faked), and crawler-operational fields like status and paused_reason are deliberately withheld from the public export — a live example of the public/admin column split. Export opens a preview panel here because the artifact viewer blocks downloads; embedded in WordPress it saves a .csv.
